attributes:
  - name: Commutative Property
    description: Changing the order doesn’t change the result.
    examples:
      - "a + b = b + a"
      - "a × b = b × a"

  - name: Associative Property
    description: Changing the grouping doesn’t change the result.
    examples:
      - "(a + b) + c = a + (b + c)"
      - "(a × b) × c = a × (b × c)"

  - name: Distributive Property
    description: Multiplication distributes over addition or subtraction.
    examples:
      - "a(b + c) = ab + ac"

  - name: Identity Property
    description: Special numbers that do not change a value.
    examples:
      - "a + 0 = a"
      - "a × 1 = a"

  - name: Inverse Property
    description: Every number has an opposite that cancels it out.
    examples:
      - "a + (−a) = 0"
      - "a × (1/a) = 1 (a ≠ 0)"

  - name: Equality Property
    description: If two expressions are equal, the same operation can be applied to both.
    examples:
      - "If a = b, then a + c = b + c"
  
methods:
  - name: Substitution Method
    description: You replace a variable with its value or another expression.
    example: "If x = 3, then in 2x + 1 → 2(3) + 1 = 7"

  - name: Elimination Method
    description: Used mostly with systems of equations. You add or subtract equations to eliminate one variable.

  - name: Balancing Method
    description: Whatever you do to one side of an equation, you do to the other to keep it equal.
    example: "x + 5 = 10 → subtract 5 from both sides → x = 5"

  - name: Factoring Method
    description: You break expressions into simpler parts (factors).
    example: "x² + 5x = x(x + 5)"

  - name: Expansion Method
    description: Opposite of factoring—multiply out brackets.
    example: "(x + 2)(x + 3) = x² + 5x + 6"

  - name: Graphical Method
    description: You draw graphs to find solutions (where lines or curves intersect).

  - name: Trial and Error
    description: You test possible values until you find the correct one.

Operation properties
Cumulative property.
This law simply states that with addition and multiplication of numbers, you can change the order of the numbers in the problem and it will not affect the answer.
For any real numbers a and b,
For addition:
a+b = b+a
For multiplication:
Ab = ba
Associative property.
This law simply states that with addition and multiplication of numbers, you can change the grouping of the numbers in the problem and it will not affect the answer.
For any real numbers a, b and c,
Addition:
a+(b+c)=(a+b)+c
Multiplication:
a(bc)=(ab)c
Distributive property.
When dealing with the distributive law, just remember to multiply everything on the inside of the parentheses by the number on the outside of the parentheses.
For any real numbers a, b and c
a(b+c)=ab+ac
(b+c)a=ba+ca
Identity property.
The identity element for addition is 0. Any number added to 0 gives you the original number.
a+0=a
The identity element for multiplication is 1. Any number multiplied by 1 gives the original number.
a∗1=a
Inverse property.
The additive inverse is the opposite of the number. Any number plus its additive inverse equals 0.
a+(−a)=0
The multiplicative inverse is the reciprocal of the number. Any nonzero number multiplied by its reciprocal equals 1.
a∗1/a=1

Factorial (!).
•  Standard Factorial
Standard Factorial (n!) – The product of all positive integers up to a given number 𝑛.
n! = n × (n - 1) × (n - 2) × ... × 1
•  Double Factorial
	Double Factorial (n!!) – The product of all integers of the same parity (odd or even) up to n.
n!! = n × (n - 2) × (n - 4) × ... × 1 (if n is odd)
n!! = n × (n - 2) × (n - 4) × ... × 2 (if n is even)
Example: 7!!=7×5×3×1=105
•  Subfactorial (Derangement)
Subfactorial (!n) or Derangement – The number of ways to arrange 𝑛 objects such that no object appears in its original position.
!n = n! × Σ ( (-1)^k / k! ), k = 0 to n
•  Multifactorial
Multifactorial (n!ᵏ) – Generalization where kk indicates the step size in multiplication.
n!ᵏ = n × (n - k) × (n - 2k) × ...
Gamma Function (Generalized Factorial)
Gamma Function (Γ(𝑛)) – A continuous extension of the factorial function, useful for non-integer values:
Γ(n) = (n - 1)!

Set Types.
Finite Set: 
A set with a limited number of elements. For example, A={1,2,3}.
Infinite Set: 
A set with an unlimited number of elements. For example, the set of all integers Z.
Empty Set:
 A set that contains no elements, denoted by ∅ or {}.
Subset:
 A set A is a subset of a set B if all elements of A are also in B. Notation: A⊆B.
Universal Set:
 The set that contains all possible elements in a particular context, usually denoted by U.
Power Set:
 The set of all subsets of a set A, including the empty set and A itself. If A={1,2}, the power set P(A)={∅,{1},{2},{1,2}}.
Countable Set:
 A set that can be put into one-to-one correspondence with the natural numbers, meaning it can be "counted." For example, the set of rational numbers Q.
Uncountable Set: 
A set that cannot be put into one-to-one correspondence with the natural numbers, such as the set of real numbers R.
Disjoint Sets:
 Two sets that have no elements in common. 
For example, A={1,2} and B={3,4} are disjoint.
Overlapping Sets:
 Sets that have some elements in common. For example, A = {1,2,3} and B={2,3,4} overlap at 2 and 3.

Set Properties.
Central Tendency:
	Mean: The average of the data set.
	Median: The middle value when data is ordered.
	Mode: The most frequently occurring value(s).
Dispersion (Spread):
	Range: The difference between the maximum and minimum values.
	Variance: The average of the squared differences from the mean, indicating how much the values vary.
	Standard Deviation: The square root of the variance, providing a measure of spread in the same units as the data.
	Convex and Non-convex
 
Shape of Distribution:
	Skewness: Measures the asymmetry of the data distribution. Positive skew means a tail on the right; negative skew means a tail on the left.
	Kurtosis: Measures the "tailedness" of the distribution, indicating the presence of outliers. High kurtosis means more outliers.
Position:
	Percentiles: Values below which a certain percentage of data falls (e.g., the 25th percentile).
	Quartiles: Specific percentiles that divide the data into four equal parts (Q1, Q2 (median), Q3).
Correlation:
	Measures the relationship between two variables. Can be positive, negative, or zero correlation.
Data Types:
	Quantitative: Numeric data, can be discrete (countable) or continuous (measurable).
	Qualitative: Categorical data, which can be nominal (no order) or ordinal (ordered).
Sample vs. Population:
	Population: The entire group being studied.
	Sample: A subset of the population used for analysis.
Outliers:
	Data points that differ significantly from other observations. They can skew results and affect measures of central tendency and dispersion.
Frequency Distribution:
	A summary of how often each value occurs in the data set, often represented in tables or histograms.
Data Collection Method:
	How the data was gathered (e.g., surveys, experiments, observational studies) can impact the properties and reliability of the data set.
Missing Data:
	Instances where data points are not available. Handling missing data is crucial for analysis and can affect results.

Basic Definitions
Matrix: A 2D rectangular array of numbers arranged in rows and columns.
Order: The dimensions of the matrix, expressed as m×n (rows × columns).
Types of Matrices.
Square Matrix: Number of rows equals the number of columns (m=nm = nm=n).
Diagonal Matrix: A square matrix where all off-diagonal elements are zero.
Identity Matrix: A diagonal matrix where all diagonal elements are 1.
Zero Matrix: All elements are zero.
Symmetric Matrix: A=ATA = A^TA=AT (equal to its transpose).
Skew-Symmetric Matrix: A=−ATA = -A^TA=−AT (transpose is the negative of the matrix).
Upper Triangular Matrix: All elements below the main diagonal are zero.
Lower Triangular Matrix: All elements above the main diagonal are zero.
Row Matrix: A matrix with only one row.
Column Matrix: A matrix with only one column.
Transpose Matrix: Obtained by swapping rows and columns (ATA^TAT).
Operations with Matrices.
Addition: Element-wise addition of matrices of the same dimension.
Subtraction: Element-wise subtraction of matrices of the same dimension.
Scalar Multiplication: Multiplying each element by a scalar.
Matrix Multiplication: Dot product of rows and columns; requires inner dimensions to match.
Hadamard Product: Element-wise multiplication of matrices of the same dimension.
Matrix Powers: Raising a square matrix to an integer power.

Commutative Property: A+B=B+AA + B = B + AA+B=B+A
Associative Property: (A+B)+C=A+(B+C)(A + B) + C = A + (B + C)(A+B)+C=A+(B+C)
Distributive Property: A(B+C)=AB+ACA(B + C) = AB + ACA(B+C)=AB+AC
Matrix Inversion: Finding A−1A^{-1}A−1 such that AA−1=IAA^{-1} = IAA−1=I; applicable only for square matrices.
Determinant: Scalar value representing the volume scaling factor of the transformation described by the matrix; only defined for square matrices.
Rank: The dimension of the vector space spanned by the rows or columns.
Trace: Sum of the diagonal elements of a square matrix.
Norm: Measure of the matrix size or length, such as Frobenius norm.

Second-Degree Polynomial Equation:
A general second-degree polynomial equation in two variables x and y is of the form:
Ax2+Bxy+Cy2+Dx+Ey+F=0
Here, the key terms that make this a second-degree equation are x^2, y^2, and potentially xy (which represents the interaction between the x and y variables). The constants A, B, C, D, E, and F determine the specific nature of the conic.
Types of Conics:
This general second-degree equation can describe different conic sections depending on the values of the coefficients. Let's look at the most common cases:
	Circle: This occurs when A=CA = CA=C and B=0B = 0B=0, and no linear terms (DDD, EEE) are present. The equation simplifies to:
A(x2+y2)=0A(x^2 + y^2) = 0A(x2+y2)=0
A circle is a special case of an ellipse where both coefficients of x2x^2x2 and y2y^2y2 are equal.
	Ellipse: If AAA and CCC are both positive (or both negative) and B=0B = 0B=0, the equation represents an ellipse. For example:
Ax2+Cy2+Dx+Ey+F=0
If A>0A > 0A>0 and C>0C > 0C>0, you get an ellipse.
	Parabola: This occurs when either A= or C=0, but not both. The equation simplifies to something like:
Ax2+Dx+Ey+F=0
or
Cy2+Dx+Ey+F=0
A parabola has a single squared term, either x2x^2x2 or y2y^2y2.
	Hyperbola: This happens when the signs of AAA and CCC are opposite (one is positive and the other is negative), and there might also be an xyxyxy term. An example would be:
Ax2−Cy2+Dx+Ey+F=0Ax^2 - Cy^2 + Dx + Ey + F = 0Ax2−Cy2+Dx+Ey+F=0
A hyperbola involves both positive and negative squared terms.
	Degenerate Cases: Sometimes the conic may degenerate into a point, a line, or a pair of lines, depending on the specific values of the coefficients.

For Functions of One Variable
	Find the Derivative:
	Compute the first derivative f′(x) of the function f(x).
	Solve for Critical Points:
	Set the first derivative equal to zero: f′(x)=0.
	Solve the equation to find the critical points x=cx = cx=c.
	Determine the Nature of Critical Points:
	Compute the second derivative f′′(x).
	If f′′(c)>0, then x=cx = cx=c is a local minimum.
	If f′′(c)<0, then x=cx = cx=c is a local maximum.
	If f′′(c)=0, the test is inconclusive; further analysis or other methods are needed.
	Check Boundary Points:
	If the function is defined on a closed interval [a,b], evaluate the function at the endpoints f(a) and f(b).
	Compare these values with the function values at critical points within the interval to find the global minimum.
Example:
For f(x)=x^2−4x+4:
	First derivative: f′(x)=2x−4.
	Set 2x−4=0  x=2.
	Second derivative: f′′(x)=2, which is positive, so x=2  is a local minimum.
	Evaluate f(2)=2^2−4⋅2+4=0.
So, the minimum value is 0 at x=2.

Homogeneous Coordinates: 
Used in projective spaces, where points are expressed in terms of an additional coordinate for transformations.
Homogeneous coordinates are a way to represent points in projective space, often used in computer graphics and geometric transformations. They extend the usual Cartesian coordinates by adding an extra dimension, which allows for transformations like perspective projections and translations to be represented using matrix operations.
In two dimensions, a point 
(𝑥,) can be represented in homogeneous coordinates as (𝑥,,), where 𝑤 is a scaling factor. The Cartesian coordinates can be obtained by dividing by 𝑤, so the point corresponds to (𝑥/𝑤,/𝑤). Similarly, in three dimensions, a point (𝑥,,) is represented as (𝑥,𝑦,𝑧,𝑤).
Homogeneous coordinates are a way to represent points in projective space, often used in computer graphics and geometric transformations. They extend the usual Cartesian coordinates by adding an extra dimension, which allows for transformations like perspective projections and translations to be represented using matrix operations.
In two dimensions, a point (x, y) can be represented in homogeneous coordinates as (x, y, w), where w is a scaling factor. The Cartesian coordinates can be obtained by dividing by w, so the point corresponds to (x/w, y/w). Similarly, in three dimensions, a point (x, y, z) is represented as (x, y, z, w).
The scaling factor in homogeneous coordinates is typically the w component. If you're given a point in homogeneous coordinates (x, y, w) in 2D or (x, y, z, w) in 3D, the scaling factor w determines how to convert the homogeneous coordinates back to Cartesian coordinates.
To find the scaling factor:
	If a point is already in homogeneous form, w is simply its last coordinate.
	If you need to normalize the point, divide each coordinate by w to obtain the Cartesian coordinates:
	In 2D: x′=x/w, y′=y/w
	In 3D: x′=x/w, y′=y/w
If you're working with transformation matrices (such as perspective transformations in computer graphics), w might be calculated as part of a matrix multiplication process.
The scaling factor w in homogeneous coordinates affects the size of the object when transforming points back to Cartesian space.
	If w>1, the point scales down, making the object appear smaller.
	If w<1 but positive, the point scales up, making the object appear larger.
	If w is negative, it can also introduce a reflection in some cases.
	If w=1, the point stays the same size.
This principle is especially important in computer graphics and perspective projections, where dividing by w simulates depth perception—objects further away have larger w-values, making them appear smaller.
In perspective projections, the w value in homogeneous coordinates often depends on the distance of an object from the viewpoint.
When applying a perspective transformation:
	Objects farther away from the camera typically have larger w-values, causing their Cartesian coordinates to shrink after division by w. This makes them appear smaller.
	Objects closer to the camera have smaller w-values, meaning after division, their Cartesian coordinates remain larger, making them appear bigger.
This is fundamental in 3D computer graphics and rendering—it's how depth perception is simulated in a scene. The projection matrix computes w dynamically based on distance, ensuring correct scaling for depth.

Ksystem=12MVCM2  +  Kinternal: motion of the whole system as one object
